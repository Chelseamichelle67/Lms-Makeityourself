# Contexto del proyecto

## Emprendimiento

**Make it Yourself** — Plataforma de cursos virtuales de automaquillaje dirigida principalmente a jóvenes y personas que quieren aprender a maquillarse desde cero o mejorar sus técnicas de maquillaje.

## Cursos

**Curso de Automaquillaje: Aprende a Maquillarte Desde Cero** — **$129.000 COP**

Precio de lanzamiento: **$89.000 COP**.

El curso enseña desde la preparación de la piel y el uso de productos básicos hasta la creación de diferentes looks de maquillaje para el día a día y ocasiones especiales.

## Ruta tecnológica

**Ruta B:** HTML, CSS y JavaScript puro + Firebase Authentication + google sheets + Google Apps Script + pasarela de pago.

La plataforma se desarrollará utilizando tecnologías web sin frameworks. Firebase Authentication permitirá gestionar el inicio de sesión de los usuarios y google sheets permitirá almacenar información relacionada con usuarios, cursos y progreso. Google Apps Script se utilizará para procesos del backend y conexión con servicios de Google. También se integrará una pasarela de pago para permitir la compra de los cursos.

## Marca

### Colores

* **Borgoña / Vino tinto:** `#8C1C2D`

  * Se utilizará principalmente en títulos, botones de llamada a la acción, bordes y elementos destacados.

* **Rosa claro:** `#FBE2E5`

  * Se utilizará como color principal de fondo y para generar una apariencia suave y agradable.

* **Blanco:** `#FFFFFF`

  * Se utilizará en tarjetas, fondos secundarios y espacios de la interfaz.

* **Gris oscuro:** `#1F2937`

  * Se utilizará principalmente para textos descriptivos y elementos secundarios.

### Tipografías

* **Montserrat**

  * Tipografía principal para textos generales, párrafos, menús, subtítulos y botones.
  * Se utilizarán diferentes pesos, desde Regular hasta Black.

* **Caveat**

  * Tipografía secundaria y manuscrita.
  * Se utilizará en títulos destacados, palabras clave y elementos que necesiten un toque más personal y artesanal.

### Tono de comunicación

El tono de la marca será **cercano, motivador y aspiracional**.

La comunicación se dirigirá directamente a la persona usuaria utilizando un lenguaje sencillo y cercano. Se busca transmitir confianza, motivación y entusiasmo por aprender.

El contenido tendrá un enfoque práctico y empático, utilizando llamados a la acción como **“¡Aprende a tu ritmo!”** y **“¡Prueba una clase!”**.
